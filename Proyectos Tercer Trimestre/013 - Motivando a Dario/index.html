Editor Canvas y Mini CAD

Proyecto de dibujo interactivo con HTML5 Canvas y JavaScript

Descripción del proyecto

Este proyecto muestra una evolución desde un sistema básico de dibujo con ratón hasta una herramienta más completa con pinceles, efecto óleo y un mini programa CAD. Está desarrollado con HTML, CSS y JavaScript utilizando el elemento Canvas.

Paso 1

Dibujo básico

Permite dibujar líneas libres moviendo el ratón sobre el lienzo.

 Paso 2

Color y grosor

Añade controles para cambiar el color y el grosor del trazo.

 Paso 3

Óleo simple

Simula un pincel cuyo trazo pierde grosor y opacidad progresivamente.

 Paso 4

Óleo avanzado

Incluye arrastre, mezcla de color y contaminación del pincel.

 Paso 5

Óleo completo

Añade duración del pincel y estampación elíptica para un efecto más realista.

 Final

Mini CAD

Herramienta final con líneas, rectángulos y círculos editables por el usuario.
Proyecto realizado con HTML5 Canvas, CSS y JavaScript.
