Proyecto WYSIWYG

Editor visual de texto creado con HTML, CSS y JavaScript

-

Javier Carrasco

Descripción del proyecto

Este proyecto muestra la evolución de un editor de texto visual en el navegador. Empieza usando un elemento editable con contenteditable y termina creando una pequeña librería reutilizable capaz de convertir textareas en editores visuales.

Paso 1

Contenteditable

Primer contenedor editable directamente desde el navegador.

 Paso 2

Botón de negrita

Se añade una barra sencilla con un botón de formato.

 Paso 3

Negrita simple

El botón aplica negrita al contenedor completo.

 Paso 4

Activar/desactivar negrita

Se permite alternar entre texto normal y texto en negrita.

 Paso 5

Editor básico

Aplica negrita sobre una selección concreta de texto.

 Paso 6

Mini editor

Añade títulos, negrita y cursiva.

 Final

Librería WYSIWYG

Convierte un textarea en un editor visual reutilizable.
