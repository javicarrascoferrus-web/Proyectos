Proyecto Canvas

Aprendizaje progresivo de gráficos con HTML5 Canvas

Descripción del proyecto

Este proyecto reúne varios ejemplos de uso del elemento Canvas en HTML5. Comienza con la creación de un lienzo básico y avanza paso a paso hasta construir un panel de control con gráficos circulares reutilizables.

Paso 1

Crear canvas

Primer lienzo HTML con tamaño definido mediante JavaScript.

 Paso 2

Contexto 2D

Obtención del contexto necesario para dibujar sobre el canvas.

 Paso 3

Color

Uso de fillStyle para definir colores de dibujo.

 Paso 4

Línea

Dibujo de líneas usando beginPath, moveTo, lineTo y stroke.

 Paso 5

Círculo

Creación de círculos mediante el método arc.

 Paso 6

Texto

Inserción de texto directamente dentro del lienzo.

 Paso 7

Porción de tarta

Dibujo de sectores circulares usando ángulos y radianes.

 Paso 8

Gráfico de tarta

Base para generar gráficos circulares con listas de datos.

 Final

Panel de control

Dashboard completo con múltiples gráficos circulares reutilizables.
Proyecto realizado con HTML, CSS y JavaScript Canvas.
